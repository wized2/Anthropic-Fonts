# Endroid Fonts

Typefaces used across **Project Endroid** surfaces (portfolio, hubs, tooling).

These files are branded for Endroid (name tables / vendor metadata). Use via `@font-face` with the Endroid family names.

## Files

| File | Family |
|------|--------|
| `anthropic_serif.ttf` | Endroid Serif |
| `anthropic_serif_italic.ttf` | Endroid Serif Italic |
| `anthropic_sans.ttf` | Endroid Sans |
| `anthropic_sans_italic.ttf` | Endroid Sans Italic |
| `jetbrains_mono.ttf` | JetBrains Mono (bundled mono) |
